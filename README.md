## `01` / About

Millihub is a technology foundation and studio based in Abuja, Nigeria. We build digital products for clients and support the people and companies shaping Africa's tech future.

Our work spans **software development, AI, blockchain, web and mobile applications, design and simulation, technology research, drone design, and aerospace technology**. Our foundation initiatives include advancing electric-mobility adoption in Nigeria with Sabi Ride Mobility Solutions Ltd.

## `02` / What’s inside

- **Company site** — about, services, team, contact, and project information
- **Project portfolio** — selected web, product design, and mobile app work
- **Interactive UI** — responsive layouts, animations, galleries, sliders, and filtering
- **Contact flows** — PHP form endpoints for contact and newsletter submissions

## `04` / Run locally

Clone the repository and start a local server from its root:

```bash
git clone https://github.com/MilliHub-dev/millihub.git
cd millihub
php -S localhost:8000
```

Open **http://localhost:8000** in your browser. You can browse the pages without PHP, but form submissions need a PHP-capable web server. Email delivery also depends on the host's mail configuration.

## `06` / Deploy

Publish the repository files to a web host that can serve static assets. If you want the forms to work, use a PHP-enabled host and configure outgoing mail. The live site is **[millihub.site](https://www.millihub.site/)**.
